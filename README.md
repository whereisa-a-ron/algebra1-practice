# Algebra 1 Practice

A self-contained offline Algebra 1 study app: 22 days of lessons, an error log,
and 50 procedural problem generators that produce unlimited fresh practice.

**Open it:** https://whereisa-a-ron.github.io/algebra1-practice/

On iPhone: open that link in Safari, then **Share → Add to Home Screen**. After
that it works with no network at all.

Everything lives in one HTML file — no server, no account, no tracking. Progress
and the error log are stored in your own browser.

Built from a private source repo; this repo holds only the published app.
